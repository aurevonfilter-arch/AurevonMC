# ARVON MC — نسخه آماده اجرا

## اجرا
1. Node.js 18+ نصب باشد.
2. در پوشه پروژه اجرا کنید:
   `npm install`
3. سپس:
   `npm start`
4. سایت روی `http://localhost:3000` بالا می‌آید.

## مالک سایت
- نام کاربری پیش‌فرض: `owner`
- رمز اولیه در فایل `.env` قرار گرفته است.
- بعد از اولین ورود، از بخش «تنظیمات سایت» رمز مالک را تغییر دهید.

## نکته امنیتی
فایل `.env` و `data.sqlite` را عمومی یا داخل Git منتشر نکنید. JWT secret و رمز مالک باید محرمانه بمانند.
